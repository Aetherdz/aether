Talk to your codebase.

aetherdz is a keyboard-first AI agent that lives in your shell. A TUI chat over your code, an MCP server for your tools, and gist or folder sync — in one native Rust binary. No Node runtime. No browser tab. No noise.

cargo install aetherdz

quick start

Install & run in three steps

01

Clone & build

One native Rust binary. No Node runtime, no browser tab.

# requires Rust 1.97+ $ git clone https://github.com/Aetherdz/aetherdz $ cd aetherdz && cargo build --release
02

Run the binary

The free zen provider works out of the box — no API key needed.

# ask a one-shot question $ ./target/release/aether ask "explain this repo"
03

Or open the TUI

Interactive chat with Ctrl+P model palette and a live token ledger.

# full terminal UI $ ./target/release/aether tui

capabilities

Everything a terminal agent needs

tui

Session list + chat

A ratatui interface with a Ctrl+P palette, wheel scroll, and a live token ledger. Pick a past session or start fresh — all from the keyboard.

mcp

MCP server

Speaks Model Context Protocol over stdio and streamable-HTTP. Your editor, your agents, and aetherdz share one context layer.

sync

Gist or folder sync

Sessions sync to GitHub gists or a local folder, merged line-by-line with origin fingerprints — no silent overwrites on concurrent edits.

native

One Rust binary

No Node runtime, no bundled Electron, no 400 MB install. Compiled, typed, and fast — the way a terminal tool should be.

tokens

Token ledger

Every request is counted. You always know what a session cost before you commit to it — no mystery usage bills.

open

MIT licensed

Public, auditable, and free. Fork it, vendor it, build on it — the crate boundary is the contract.
